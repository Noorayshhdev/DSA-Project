# 🎓 Result Analysis System

A Java-based console application designed to manage and analyze student academic results. It calculates total marks, percentages, and grades, generates rank lists, identifies the class topper, and calculates the class average.

## ✨ Features

- 📝 Add student details and marks for 3 subjects
- 🧮 Calculate total marks and percentage
- 🏆 Automatically assign grades
- 🔍 Search student results by name
- 📊 Generate a rank list based on total marks
- 🥇 Find the class topper
- 📈 Calculate the class average
- 💾 Save and load student records using file handling
- ⚠️ Validate marks and prevent duplicate student entries

## 🛠️ Technologies Used

- ☕ Java
- 📚 ArrayList
- 🗂️ HashMap
- 🔎 Searching
- ↕️ Sorting
- 📁 File Handling

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code or any Java IDE.
3. Compile the Java file:

   ```bash
   javac Main.java
   ```

4. Run the application:

   ```bash
   java Main
   ```
